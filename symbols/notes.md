Favicon
-------
In order to use the svg in https://realfavicongenerator.net, the svg produced by Affinity has to be manually modified to remove `width` and `height` in the `svg viewBox` element.

Related issue: https://github.com/RealFaviconGenerator/realfavicongenerator/issues/520

Style for light and dark schemes has to be manually added too.
